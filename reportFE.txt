## 4. Cloudinary signed photo upload
- New `lib/upload.ts`:
  - Mock mode: downscale on canvas → data URL (works fully offline).
  - Real mode (`NEXT_PUBLIC_API_URL` set): POST /api/upload/cloudinary-signature
    → unsigned upload to Cloudinary → secure_url. Signature/key/folder all served;
    API secret never shipped.
- Registration (Step 2) now has a required photo field with preview + error
  states; `profile_image` is in `RegisterPayload`, persisted to session.
- `lib/session.ts` SessionUser extended (gender/phone/address/birth/bio/photo);
  `apiMe` maps them onto the member so the card/profile reflect the registrant.
- Later photo change: wire to `PUT /api/members/me/photo` once the profile-edit
  page exists (not present in this mock app yet).
